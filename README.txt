SETUP (Windows / VS Code)
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: py -m pip install -r requirements.txt
4. Run: py app.py
5. Visit http://127.0.0.1:5001/

HOME ARTWORK
The Home page is already styled to use your supplied illustration.
Copy the anime-girl drawing image into:
  static/images/home-art.png
Keep that exact filename. If it is missing, the page displays an aqua fallback illustration panel instead of breaking.

Pokémon sprites load from PokeAPI's public sprite repository and need internet access.
